## 🚀 Project Overview

**State-wise GST Revenue Analysis in India Using Python** is a data analytics project that explores GST collection patterns across Indian States and Union Territories.

The project applies Python-based analytics techniques to perform:

✅ Data Cleaning  
✅ Exploratory Data Analysis (EDA)  
✅ Statistical Analysis  
✅ Revenue Trend Analysis  
✅ State-wise Comparison  
✅ Growth Analysis  
✅ Seasonal Analysis  
✅ Anomaly Detection  
✅ Interactive Dashboard Development  

The objective is to transform raw GST collection data into meaningful business and policy insights. :contentReference[oaicite:1]{index=1}

---

# 🎯 Business Objectives

The project focuses on:

📌 Comparing GST revenue contribution across states  
📌 Understanding monthly and yearly revenue trends  
📌 Measuring CGST, SGST, IGST, and CESS contribution  
📌 Identifying top and bottom revenue contributors  
📌 Calculating YoY and MoM growth rates  
📌 Detecting unusual GST collection patterns  
📌 Supporting data-driven revenue planning
